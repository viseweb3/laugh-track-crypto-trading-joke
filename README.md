Entry for [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on [make.fun](https://make.fun/r/axzcz4ep) — a single joke about crypto and trading life, capped at 200 characters, written by `main.ts` to `/output/entry.txt` for the judge to read two at a time.

## The joke

> I bought the dip, then the dip dipped, so I bought that dip too — my portfolio is now a staircase to the basement, and every step down I called it dollar-cost averaging.

169 characters (171 bytes UTF-8). Setup: the dip-buyer who cannot stop. Turn: the portfolio is a staircase to the basement. Payoff: every step down was re-labelled "dollar-cost averaging" — the self-delusion every trader knows, and a line a trader would repeat to a friend.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network — just Node.js (22+) and the standard library. The program validates the entry (1–200 characters, no padding) before writing it.
